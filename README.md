# Microsoft 365 Help Desk Lab

## Overview
This project demonstrates hands-on experience with Microsoft 365 core collaboration tools from an IT Support / Help Desk perspective.

The lab simulates a small organization environment where I performed user administration and supported Outlook, Teams, OneDrive, and SharePoint workflows.

---

## Environment

- Microsoft 365 Business Basic
- Two users created:
  - Surbhi Admin (Global Administrator)
  - Test User (Standard Employee)

---

## Tasks Completed

### User Administration
- Created users in Microsoft 365 Admin Center
- Assigned Microsoft 365 Business Basic licenses

### Outlook
- Sent and received emails between users
- Created calendar meetings

### OneDrive
- Uploaded files
- Shared documents with permissions

### Microsoft Teams
- Created Team
- Added members
- Sent and received chat messages
- Scheduled and received Teams meetings

### SharePoint
- Accessed SharePoint site
- Uploaded document to Document Library

---

## Skills Demonstrated

- Microsoft 365 Admin Center
- User & license management
- Outlook email and calendar support
- OneDrive file sharing
- Microsoft Teams collaboration
- SharePoint document libraries
- Screenshot-based documentation

---

## Goal

To demonstrate practical Microsoft 365 experience aligned with entry-level IT Support / Help Desk responsibilities.
